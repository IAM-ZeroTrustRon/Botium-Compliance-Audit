# Botium Toys — Internal Controls and Assurance Review

**Ron Richardson | Fictional GRC training assessment | October 6, 2026**

This project turns scenario-described control weaknesses into evidence requests, audit-style observations and accountable treatment decisions. It covers access, data protection, recovery, monitoring and governance for a retail/e-commerce organization.

| Deliverable | Decision supported |
|---|---|
| [Controls and assurance matrix](controls-checklist/controls.md) | Objectives, artifacts, satisfactory evidence and gap criteria |
| [Audit-style findings](findings/audit-findings.md) | Condition, criteria, unknown cause, impact, proposed treatment and closure |
| [Risk view](risk-analysis/risk-heat-map.md) | Qualitative scenario priorities |
| [Treatment plan](recommendations/remediation.md) | Proposed owners, review targets and closure evidence |
| [Posture diagram](diagrams/mermaid-diagram.md) | Scenario concerns and proposed treatments |

The underlying checklist PDF is not retained here. Configurations, interviews and tests were not reviewed. All matrix statuses remain **Pending Verification (Evidence Gap)**; previous summary counts are not used as verified assurance measures. NIST CSF 2.0 guides objectives. PCI DSS/GDPR applicability requires scope review. SOC 1 and SOC 2 are distinct assurance engagements; this is neither report nor certification. No actual incident, legal violation or implemented risk reduction is asserted.
